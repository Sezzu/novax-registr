# Обложка

`royal-battle.png` создана встроенным imagegen для Telegram-поста NovaX. Широкий формат приблизительно 16:9 (1672×941). Содержит только NOVAX / NEW ERA, детали события остаются в подписи.

Промпт: кинематографическая Minecraft-арена королевской битвы, четыре воксельных игрока с легендарным оружием, каменная крепость, рассвет и искры, минимальные надписи NOVAX и NEW ERA, без даты, времени, IP и основного текста.

У существующего события путь записан как `assets/royal-battle.png`. Заменить обложку можно через `/edit_event` → «Обложка» (отправьте изображение 16:9), либо `/set ID cover_image assets/имя.png`. Для новой установки обложку задаёт администратор.

Полный промпт встроенного imagegen:

Use case: ads-marketing. Asset type: Telegram channel event cover for Minecraft server NovaX — New era. Generate a polished cinematic voxel Minecraft-style royal battle arena cover, EXACT 16:9 landscape composition (1920x1080 or proportional 16:9). Four blocky player silhouettes with legendary weapons facing a ruined stone arena, sunrise light and sparks, adventurous competitive mood, refined dark stone with warm golden lighting, crisp highly readable composition on a mobile screen. Minimal text, exact title only: 'NOVAX' and small subtitle 'NEW ERA'. No event date, no time, no IP, no body text, no UI elements, no watermarks, no mock Telegram screenshot. This is a real cover bitmap; all event information stays in the Telegram caption.
